## Задачи:
1. умножение вектора на матрицу
2. интегрирование прямоугольниками
3. решение линейных алгебраических урвнений

## Железо:
Процессор: 40 потоков, 20 ядер(Intel Xeon Gold 6248 @ 2.50 GHz)

Опреративная память: 12 свободных гигабайт для vector-matrix (40 000 * 40 000 * 8/2^30 = 11,92)

## Сбор проекта

```bash
mkdir build
cd build
cmake ..
cmake --build . 
```

## Запуск 
```bash
./vector-matrix
./slau
./integrate
```
## Генерация отчета
```bash
python results.py
```
